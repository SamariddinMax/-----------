## 🌟 О проекте

**Smart Converter** — это стильный и удобный веб-конвертер, который помогает быстро переводить значения из одной единицы измерения в другую.

Проект создан с акцентом на современный дизайн, простоту использования и комфортную работу прямо в браузере. 💙

### 🚀 Возможности

- 📏 **Длина** — конвертация единиц длины.
- ⚖️ **Вес** — перевод единиц массы.
- 🌡️ **Температура** — преобразование температурных значений.
- 🔄 **Обмен единиц** — быстрая смена исходной и целевой единиц.
- 📋 **Копирование результата** — удобно копировать вычисленное значение.
- ✨ **Анимации и визуальные эффекты** — декоративные элементы и интерактивный курсор.
- 📱 **Адаптивный интерфейс** — возможность настроить отображение для компьютеров и смартфонов.
- ⚡ **Работа в браузере** — без необходимости устанавливать отдельную программу.

> 💡 Точность конвертации и доступные единицы зависят от реализации в файле `script.js`.

## 💻 Как запустить проект

### Способ 1 — открыть в браузере

1. 📥 Скачай или клонируй репозиторий.
2. 📂 Открой папку проекта.
3. 🌐 Запусти файл `index.html` в браузере.

### Способ 2 — через VS Code

1. Открой папку проекта в Visual Studio Code.
2. Установи расширение **Live Server**, если оно ещё не установлено.
3. Нажми правой кнопкой мыши на `index.html`.
4. Выбери **Open with Live Server**.

Готово! 🎉 Сайт откроется в браузере.

## 🎯 Как пользоваться

1. 🧩 Выбери категорию: длина, вес или температура.
2. 🔢 Введи исходное значение.
3. 📥 Выбери единицу, из которой нужно выполнить перевод.
4. 📤 Выбери целевую единицу.
5. ✨ Нажми «Конвертировать».
6. 📋 При необходимости скопируй результат.
